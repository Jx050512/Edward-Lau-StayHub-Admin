# Edward Lau — StayHub Admin (Netlify-ready)

Admin static website. The API route `/api/*` is proxied to `https://stayhub-public.netlify.app/api/*`.

Create a separate **private GitHub repository** and upload the **contents** of this folder at repository root. On Netlify import it in the **same team** as Public.

Build command: leave blank. Base directory: blank. Publish directory: `site`. `netlify.toml` configures the `/api/*` proxy.

After deployment check `https://YOUR-ADMIN-SITE.netlify.app/api/ready` and compare with `https://stayhub-public.netlify.app/api/ready`.

No `.env` or database files are needed in this Admin repository; secrets remain only on the Public site's Netlify environment variables.

Email OTP is sent by the Public API (the current demo uses Gmail SMTP via `STAYHUB_EMAIL_PROVIDER=gmail`). MFA remains mandatory; no bypass is included. The Admin site itself does not hold Gmail credentials.


## Database Export (Privacy-safe reports)

New **Database export** menu (next to Analytics). Excel (multiple sheets) and CSV (one selected dataset) are generated by the authenticated **Public** API `/api/admin/reports/export`. Full names/emails, passwords, hashes, OTPs, phone numbers, special requests, and tokens are never included. Demo payments remain labelled as simulated.

**Important:** Deploy the updated Public backend first (adds the protected endpoint), then deploy the updated Admin frontend. Both sites must remain connected through Admin `netlify.toml` proxy. There are no new environment variables or database migrations. Do not share downloaded reports publicly. This is not a `.sql` backup for academic submissions.
